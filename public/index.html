REST Specifications

Available Microservice Endpoints

All endpoints execute strictly in RAM without external database roundtrips.

POST /v1/validate
Latency: < 1 ms

Validates an individual international phone number. Accepts raw digits, standard formats, or national numbers with optional defaultCountry.

Payload: {"phone": "+523312345678", "defaultCountry": "MX"}
POST /v1/validate/batch
Batch capacity: Up to 50 concurrent numbers

Executes ultra-fast bulk validation. Returns an aggregated summary (total, valid, invalid, allow, review, block) and full intelligence array.

Payload: {"numbers": ["+14155552671", "+523312345678", "+34612345678"]}
GET /v1/validate?phone={number}&country={iso}
Optimized for query string integrations

Direct GET method returning identical canonical schema as the POST route.

GET /health
Keep-alive & monitoring probe

Outputs microservice uptime, memory consumption in MB (RSS and Heap), and health operational status.
